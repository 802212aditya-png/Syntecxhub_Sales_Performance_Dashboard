#  Sales Performance Dashboard

# Project Overview

The Sales Performance Dashboard is a data analytics and visualization project developed as part of the **Syntecxhub Data Analysis Internship Program**.

The objective of this project is to analyze sales data and transform raw business data into meaningful insights using an interactive dashboard.

The dashboard helps understand sales performance across different time periods, products, regions, and categories while tracking important business KPIs.



# Project Objectives

The main objectives of this project are:

- Clean and preprocess the raw sales dataset
- Analyze monthly sales trends
- Analyze quarterly sales trends
- Analyze yearly sales performance
- Identify top-selling products
- Identify low-performing products
- Compare sales performance across different regions
- Compare performance across different product categories
- Calculate important business KPIs
- Create an interactive sales dashboard
- Generate meaningful business insights from the data



#  Tools & Technologies

- Power BI – Dashboard development and visualization
- Microsoft Excel / CSV – Data storage and preprocessing
- Data Cleaning – Handling missing values and duplicates
- Data Analysis – Sales performance analysis
- Data Visualization – Charts, graphs and KPI cards
